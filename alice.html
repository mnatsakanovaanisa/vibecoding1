Python Academy: Быстрый старт

Урок 1: Переменные и вывод

Базовый

Теория: В Python переменные создаются присваиванием. Функция print() выводит данные на экран.

Задача: Создай переменную name со значением "Алиса" и выведи приветствие: "Привет, Алиса!".

Урок 2: Условные операторы (if/else)

Средний

Теория: Конструкция if проверяет условие. Если оно истинно, выполняется блок кода.

Задача: Напиши код, который проверяет: если число age больше или равно 18, выведи "Доступ разрешен", иначе "Доступ запрещен". Установи age = 20.

Урок 3: Циклы и списки

Продвинутый

Теория: Цикл for позволяет перебирать элементы списка. Списки создаются через квадратные скобки [].

Задача: Дан список фруктов. Пройдись циклом по списку и выведи каждый фрукт в формате: "Я люблю [фрукт]".
